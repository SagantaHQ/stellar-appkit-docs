## What is Stellar AppKit?

A **Web3Modal / Reown AppKit equivalent for Stellar** — one unified wallet API, a first-class Soroban layer, real transaction previews instead of raw XDR, and a themeable UI that works identically dropped into any site.

## Key Features

### Wallet Connectivity
Freighter, Albedo, xBull, Ledger, and WalletConnect — unified SEP-43 interface. Network mismatch recovery with auto-retry, hardware wallet multi-account support, and cross-tab session sync.

### Transaction Preview
Every operation decoded into plain language with risk flags, contract verification badges, fee estimates, and balance-delta previews — all *before* the wallet's signature prompt.

### Soroban Integration
Build, simulate, prepare, sign, submit, and poll with a single `invoke()` call. Typed contract clients, RPC failover, auth-entry signing, and pre-simulate fee estimation built in.

### Sign-In With Stellar
Self-issued auth flow with SEP-0053 signing support, multi-candidate verification, and a server-side verifier package. Debug diagnostics for diagnosing verification failures.

### Framework Wrappers
React, Vue, Solid, and Svelte — same hooks (`useConnect`, `useSession`, `useSoroban`), tree-shakable subpath exports. Only ship the framework you use.

### Themeable UI
Shadow DOM Web Component with modal, bottom-sheet, and inline presentation. **Zero runtime dependencies** — drag-to-dismiss uses a custom 30-line spring engine, open/close transitions use native WAAPI. Every color, radius, and font is a CSS custom property.

## Packages

| Package | Description |
|---|---|
| `@saganta/stellar-appkit` | Core SDK — wallet connections, Soroban, transaction preview, framework wrappers |
| `@saganta/stellar-appkit-ui-web` | Web UI — `<stellar-appkit-modal>` Shadow DOM Web Component + framework wrappers for React, Vue, Solid, Svelte |
| `@saganta/stellar-appkit-siws-verify` | Server-side SIWS signature/envelope verification |

## Install

```bash
npm install @saganta/stellar-appkit @saganta/stellar-appkit-ui-web
```

All wallet SDKs and the Stellar SDK are bundled as regular dependencies — installed automatically, version-locked, tree-shaken if unused. The UI package has zero runtime dependencies.

## Quick Example

```ts
import { StellarAppKit } from '@saganta/stellar-appkit';
import '@saganta/stellar-appkit-ui-web';

// connectors is optional — defaults to Freighter, Albedo, xBull, Ledger
// domain + uri are optional too — auto-derived from window.location in the browser
const appkit = new StellarAppKit({
  network: 'TESTNET',
  appMetadata: { name: 'Example App' },
});

const modal = document.querySelector('stellar-appkit-modal');
modal.client = appkit;
modal.open();
```
